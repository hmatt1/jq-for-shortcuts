JQ for Shortcuts Support

How do I run a filter in a shortcut?

Add Run JSON Filter after the action that gets your JSON, such as Get Contents of URL. Type a filter, such as .items[] | .name, and set Input to the JSON. The action works without opening the app first. To test a filter before putting it in a shortcut, use the Playground in the app.

Which output mode should I pick?

One item per result works for most shortcuts: each result becomes its own item, and a filter that returns one list gives its items. One JSON array keeps every result in one list. Raw text lines gives text with one result per line, with strings unquoted, which suits notifications and messages. Compact JSON and Pretty JSON give the results as JSON text.

Objects and lists arrive as JSON text, which Get Dictionary Value and the other dictionary actions read directly. A JSON null arrives as the text null.

How do I pass a value from my shortcut into a filter?

Use Arguments. Pass a Dictionary, and each key becomes a variable in the filter: the key limit is $limit. Pass a Number to get a number and text to get a string. Names use letters, digits and underscores, and start with a letter or underscore.

Where do my saved filters appear?

Tap Save Filter in the Playground. The filter appears right away in the Run Saved Filter action's picker, with its description below the name, and in the Library tab. If Shortcuts was open, close the picker and open it again.

The action says the input is too large, or the filter timed out

A run in the background takes inputs up to 50 MB and stops after its Timeout, at most 25 seconds. Turn on Run in App under Show More: the app opens with a progress screen, runs the filter with inputs up to 250 MB and a longer Timeout, and returns the result to the shortcut.

Which jq features are missing?

The app supports jq 1.7 syntax and builtins. For safety it turns off everything that reads files or the environment: include, import, input, inputs, input_filename, env and $ENV. Pass values in Arguments instead. The Reference tab lists the remaining differences from jq 1.7.

How do I add the example shortcuts?

Open the Library tab and tap Example Shortcuts. Each example lists its actions in order, the filter to paste, and the values to change, such as a URL or field names. Try in Playground runs its filter on a sample input.

Can I open the app from the Action Button, the Lock Screen or the share sheet?

Yes. In Settings, Action Button, choose Shortcut, then JQ for Shortcuts, then Open Playground. On the Lock Screen or in Control Center, add the Open Playground or Run Saved Filter on Clipboard control. In Files or any app that shares JSON, choose JQ for Shortcuts in the share sheet to open the JSON in the Playground or run a saved filter on it.

Does this app collect any data?

No. See the Privacy Policy. Filters run on the device, and the app makes no network requests.
